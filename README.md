# astrbot_plugin_gscode

获取米哈游游戏（原神/星穹铁道/绝区零）前瞻直播兑换码。

通过米游社官方API自动发现直播活动并获取兑换码，无需手动输入活动ID。

## 安装

将 `astrbot_plugin_gscode` 文件夹放到 AstrBot 的 plugins 目录下，重启 AstrBot 即可自动安装依赖。

## 命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `/gicode` | `原神兑换码` | 获取原神前瞻直播兑换码 |
| `/hsrcode` | `崩铁兑换码` | 获取崩坏：星穹铁道前瞻直播兑换码 |
| `/zzzcode` | `绝区零兑换码` | 获取绝区零前瞻直播兑换码 |
| `/兑换码` | `redeemcode` | 获取所有游戏的兑换码 |

## 自动触发（群聊）

插件支持关键词自动触发，无需输入命令前缀：

| 用户消息示例 | 自动触发 |
|-------------|---------|
| "原神兑换码有吗" | 原神 |
| "崩铁兑换码" | 星穹铁道 |
| "绝区零前瞻码" | 绝区零 |
| "有兑换码吗" / "兑换码怎么查" | 全部游戏 |

## LLM 工具注册

插件向 AstrBot 的 LLM 系统注册了以下工具，LLM 可在对话中自动调用：

| 工具名 | 说明 |
|--------|------|
| `get_genshin_code` | 获取原神兑换码 |
| `get_hsr_code` | 获取崩铁兑换码 |
| `get_zzz_code` | 获取绝区零兑换码 |
| `get_all_codes` | 获取全部兑换码 |

## 原理

两阶段获取策略：

1. **主策略：米游社官方API** - 扫描官方账号帖子提取 `act_id`，调用 `miyolive` 接口获取兑换码
   - 原神：原神 (uid=75276539)
   - 星穹铁道：星穹米游姬 (uid=80823548)
   - 绝区零：绝区零 (uid=152039148)
2. **备选：B站评论区** - 搜索B站最新视频，从评论区提取兑换码

## 数据来源

| 游戏 | 主策略 | 备选 |
|------|--------|------|
| 原神 | 米游社miyolive API | B站评论区 |
| 星穹铁道 | 米游社miyolive API | B站评论区 |
| 绝区零 | B站评论区（无miyolive活动） | - |
